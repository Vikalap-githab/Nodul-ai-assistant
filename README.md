# ИИ-ассистент контроля поручений (Nodul + Google Workspace + LLM)

Выпускной проект программы «Специалист по внедрению систем ИИ».

## Задача
Избавить руководителя от ручного контроля поручений: система сама извлекает задачи
из писем (включая неструктурированные — через LLM), валидирует данные, назначает
приоритеты, шлёт напоминания и собирает отчёты.

## Что сделано
- Хронометраж и моделирование AS-IS/TO-BE (Swimlane, RACI): ручной контроль стоил 2 часа в день
- 73 узла автоматизации в Nodul, 2 workflow (событийный + регламентный)
- 3 канала ввода: веб-форма, шаблонное письмо, неструктурированное письмо с ИИ-парсингом (Llama 3.1 70B)
- Принцип «ИИ извлекает — система верифицирует»: детерминированная валидация по справочнику, карантин для невалидных данных
- Напоминания с идемпотентностью и «тихими часами», ежедневный и еженедельный отчёты
- Тестирование: 10 прогонов, 14 дефектов выявлено и исправлено, 100% успешность

## Результаты
- Контроль поручений: с 10 часов в неделю до 5–10 минут в день
- Потерянные поручения: с 15–20% до <2%
- Экономия ~4 млн ₽/год, окупаемость 1–3 месяца (3 сценария внедрения, ROI 276–1183%)
